# Практика: пошук товарів

Створи застосунок пошуку товарів за назвою. Користувач вводить пошукове
слово, надсилає форму та отримує картки товарів із публічного API DummyJSON.

Розмітка, стилі, контейнер товарів і loader уже підготовлені. Основну логіку
потрібно написати у `src/main.js`, а HTTP-запит — у
`src/js/products-api.js`.

## Підготовка проєкту

Відкрий термінал у корені шаблону та встанови готові залежності:

```bash
npm install
```

Встанови Axios:

```bash
npm install axios
```

Після встановлення залежностей запусти локальний сервер:

```bash
npm run dev
```

## Готова структура

```text
src/
├── index.html
├── main.js
├── css/
│   └── styles.css
└── js/
    └── products-api.js
```

Не створюй додаткові HTML-, CSS- або JavaScript-файли. Розмітку та стилі
змінювати не потрібно.

У `index.html` уже є:

- форма `.search-form`;
- поле `query` для пошукового слова;
- кнопка відправлення форми;
- loader із класами `.loader` та `.is-hidden`;
- елемент `.message` для повідомлень;
- список `.product-list` для карток товарів.

## HTTP-запит

Для пошуку використовуй публічний
[DummyJSON Products API](https://dummyjson.com/docs/products). Реєстрація та
API-ключ не потрібні.

Базова адреса пошуку:

```text
https://dummyjson.com/products/search
```

У файлі `products-api.js`:

1. Імпортуй Axios.
2. Створи та експортуй функцію `getProductsByQuery(query)`.
3. Виконай GET-запит за базовою адресою.
4. Передай параметри через властивість `params` конфігурації Axios:
   - `q` — пошукове слово;
   - `limit` — максимальна кількість товарів, значення `8`;
   - `delay` — затримка відповіді, значення `1000`.
5. Поверни з функції `response.data`.

API повертає об’єкт такого вигляду:

```js
{
  products: [],
  total: 0,
  skip: 0,
  limit: 8
}
```

Масив знайдених товарів знаходиться у властивості `products`.

## Обробка форми

У `main.js`:

1. Імпортуй `getProductsByQuery` із `products-api.js`.
2. Знайди форму, loader, повідомлення та список товарів.
3. Додай до форми обробник події `submit`.
4. Скасуй стандартне перезавантаження сторінки.
5. Отримай значення поля `query` і прибери пробіли по краях.
6. Якщо рядок порожній, покажи повідомлення «Введіть назву товару» та не
   виконуй HTTP-запит.
7. Перед новим запитом очисти повідомлення та попередні картки.
8. Покажи loader.
9. Виклич `getProductsByQuery(query)`.

## Відображення товарів

У `main.js` створи функцію `createProductsMarkup(products)`.

Для кожного товару створи картку, яка містить:

- зображення з властивості `thumbnail`;
- назву з властивості `title`;
- ціну з властивості `price`;
- рейтинг із властивості `rating`.

Функція повинна повернути один рядок із готовою розміткою. Додай усі картки
до `.product-list` однією операцією через `innerHTML`.

## Обробка результату

Результат запиту оброби через `then()`, `catch()` і `finally()`.

### `then()`

- отримай масив `products`;
- якщо масив порожній, покажи повідомлення «Товарів за вашим запитом не
  знайдено»;
- якщо товари є, створи та додай їхні картки.

### `catch()`

Покажи повідомлення «Не вдалося завантажити товари. Спробуйте ще раз».

### `finally()`

Приховай loader незалежно від результату запиту.

## Loader

Створи дві функції:

- `showLoader()` прибирає клас `is-hidden`;
- `hideLoader()` додає клас `is-hidden`.

Loader має з’являтися перед HTTP-запитом і зникати після його завершення.

## Перевірка роботи

- Порожня форма не відправляє запит.
- Під час запиту відображається loader.
- Пошук `phone` показує картки товарів.
- Новий пошук очищає попередні картки.
- Для запиту без результатів відображається зрозуміле повідомлення.
- Після успіху або помилки loader зникає.
- У Network видно GET-запит із параметрами `q`, `limit` і `delay`.
- У консолі немає необроблених помилок.
