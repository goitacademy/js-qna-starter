# Q&A-сесія: основи JavaScript M1

### 🟢 Задача 1. Дані профілю

Оголосити незмінні й змінні дані профілю, змінити онлайн-статус та перевірити
тип кожного значення.

**Що тренуємо:** `const`, `let`, повторне присвоєння, примітивні типи, `null`,
`undefined`, оператор `typeof`.

### 🟢 Задача 2. Виправ оголошення змінних

Знайти різні помилки в готовому коді й виправити його без зміни очікуваного
повідомлення.

**Що тренуємо:** вибір між `const` і `let`, найменування змінних і типові
помилки JavaScript.

### 🟢 Задача 3. Пакування товару

Обчислити кількість повних коробок, залишок товарів і нову кількість після
надходження на склад.

**Що тренуємо:** ділення, `%`, `Math.floor()`, комбінований оператор `+=`.

### 🟢 Задача 4. Короткий код запрошення

Створити код із першого й останнього символів рядка та його довжини, після чого
сформувати повідомлення.

**Що тренуємо:** індексацію рядка, `length`, незмінність рядків, шаблонні рядки.

### 🟢 Задача 5. Рядок і число

Порівняти конкатенацію числових рядків із явним числовим перетворенням та
перевірити типи результатів.

**Що тренуємо:** `Number()`, конкатенацію, числові рядки, `typeof`, явне й
неявне перетворення типів.

### 🟢 Задача 6. Передбач результати порівнянь

До запуску передбачити результати порівнянь, пояснити різницю між нестрогою і
строгою рівністю та виконати коректне явне перетворення.

**Що тренуємо:** `>`, `==`, `===`, порівняння рядків, перетворення операндів.

### 🟡 Задача 7. Код підтвердження

Згенерувати випадковий шестизначний код у заданому числовому діапазоні та
перевірити тип результату.

**Що тренуємо:** `Math.random()`, `Math.floor()`, роботу з мінімальною та
максимальною межами діапазону, оператор `typeof`.

### 🟡 Задача 8. Діапазон цін

Знайти найменшу, найбільшу й середню ціну та різницю між межами діапазону.

**Що тренуємо:** `Math.min()`, `Math.max()`, арифметику й округлення.

### 🟡 Задача 9. Вартість поїздки

Реалізувати функцію, яка приймає числа або числові рядки, обчислює витрату
пального та повертає вартість поїздки.

**Що тренуємо:** оголошення і виклик функції, параметри, аргументи, `Number()`,
локальні змінні, `return`.

### 🔴 Задача 10. Порядок виконання функцій

Розставити `console.log(1)`, `console.log(2)` і `console.log(3)` до, всередині
та після вкладеного виклику функції, а потім передбачити порядок виведення.

**Що тренуємо:** вкладені виклики функцій, призупинення зовнішньої функції на
час внутрішнього виклику, повернення значення та локальну область видимості.
