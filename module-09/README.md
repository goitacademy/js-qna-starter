# Практика: планувальник подій

Створи застосунок, у якому користувач може запланувати подію, вибрати для неї
дату й час, переглянути список подій і видалити непотрібну подію. Дані мають
зберігатися після перезавантаження сторінки.

HTML-розмітка та стилі вже підготовлені у стартовому шаблоні. Основну роботу
виконуй у файлі `src/main.js`.

Для вибору дати й часу використай бібліотеку
[Flatpickr](https://flatpickr.js.org/). Встанови її через npm і підключи до
проєкту за допомогою `import`.

## Підготовка проєкту

Відкрий термінал у корені стартового шаблону та встанови його залежності:

```bash
npm install
```

## Встановлення Flatpickr

Встанови бібліотеку командою:

```bash
npm install flatpickr
```

У головному JavaScript-файлі імпортуй бібліотеку та її стилі:

```js
import flatpickr from 'flatpickr';
import 'flatpickr/dist/flatpickr.min.css';
```

Після встановлення Flatpickr запусти локальний сервер:

```bash
npm run dev
```

## Готові файли

Стартовий шаблон уже має необхідну структуру:

```text
src/
├── index.html
├── main.js
└── css/
    └── styles.css
```

Не створюй додаткові HTML-, CSS- або JavaScript-файли. Готові стилі змінювати
не потрібно.

У `index.html` уже є:

- заголовок застосунку;
- форма з класом `event-form`;
- текстове поле з ім’ям `title` для назви події;
- текстове поле з ім’ям `date` і класом `js-date-input` для Flatpickr;
- кнопка типу `submit` з текстом «Додати подію»;
- порожній список із класом `event-list`.

Файл `main.js` уже підключений до сторінки як модуль. На початку роботи знайди
форму, поле дати та список подій за їхніми класами.

## Налаштування календаря

У `main.js` знайди поле `.js-date-input` та передай його функції `flatpickr`.

Додай такі налаштування:

- користувач може вибирати дату й час;
- використовується 24-годинний формат;
- формат значення — `Y-m-d H:i`;
- не можна вибрати дату раніше за сьогодні.

## Об’єкт події

Кожна подія повинна мати таку структуру:

```js
{
  id: 1720000000000,
  title: 'Консультація з ментором',
  date: '2026-09-15 18:30'
}
```

Для створення унікального числового `id` використай `Date.now()`.

## Додавання події

1. Прослуховуй подію `submit` на формі.
2. Скасуй стандартне перезавантаження сторінки.
3. Отримай значення полів `title` і `date`.
4. Прибери пробіли по краях назви події.
5. Якщо хоча б одне поле порожнє, покажи повідомлення і не додавай подію.
6. Створи об’єкт події та додай його до масиву `events`.
7. Збережи оновлений масив у локальному сховищі.
8. Повторно відобрази список.
9. Очисти форму та вибрану у Flatpickr дату.

## Створення розмітки

У файлі `main.js` створи функцію `createEventsMarkup(items)`.

Функція повинна:

- отримувати масив подій;
- створювати для кожної події елемент списку;
- показувати назву, дату й кнопку «Видалити»;
- зберігати `id` події в `data-id` кнопки;
- повертати один рядок із готовою розміткою;
- показувати повідомлення, якщо масив порожній.

Використай цю функцію для заповнення `.event-list`.

## Робота з локальним сховищем

У файлі `main.js` створи дві функції для роботи зі сховищем.

### `saveEvents(key, events)`

- отримує ключ і масив подій;
- перетворює масив на JSON-рядок;
- записує рядок у `localStorage`.

### `loadEvents(key)`

- отримує ключ;
- читає значення з `localStorage`;
- повертає порожній масив, якщо збережених даних немає;
- перетворює JSON-рядок назад на масив;
- використовує `try...catch` і повертає порожній масив, якщо JSON пошкоджений.

Під час запуску застосунку завантаж збережені події та одразу відобрази їх.

Використовуй ключ `event-planner-items`.

## Видалення події

1. Додай один обробник `click` на список `.event-list`.
2. Ігноруй натискання не на кнопку.
3. Прочитай `id` події з `data-id` натиснутої кнопки.
4. Створи новий масив без відповідної події за допомогою `filter()`.
5. Запиши оновлений масив у `localStorage`.
6. Повторно відобрази список.

## Перевірка роботи

- Flatpickr відкривається після натискання на поле дати.
- Не можна додати подію з незаповненими полями.
- Нова подія з’являється у списку.
- Подія видаляється відповідною кнопкою.
- Після оновлення сторінки список відновлюється.
- Пошкоджений JSON у сховищі не зупиняє роботу застосунку.
- У консолі немає необроблених помилок.
