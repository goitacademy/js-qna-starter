# Q&A-сесія: делегування, бібліотеки та деструктуризація

## Мета

Надати студентам відповіді на запитання щодо навчального матеріалу, домашніх
завдань, проєктів і практичного застосування знань.

## Тривалість

**1,5 години**

## Основний принцип

Переважна частина зустрічі присвячена відповідям на запитання студентів.
Практика є додатковою та не повинна витісняти основний Q&A-блок.

## 1. Початок зустрічі

⏱️ 5–10 хв

- Привітайте студентів і проведіть короткий смол-ток про перебіг навчання.
- Представтеся, якщо працюєте з групою вперше.
- Перевірте звук, відео та демонстрацію екрана.
- Відкрийте таблицю із запитаннями та зберіть додаткові питання.
- Озвучте план: спочатку всі запитання, потім практика за наявності часу.

### Як задати хороший тон

- Подякуйте за підготовлені запитання та наголосіть, що будь-яке запитання
  доречне.
- Нагадайте, що помилки є нормальною частиною навчання.
- Не називайте питання або тему «легкими» чи «очевидними».
- Заохочуйте участь без тиску на окремих студентів.

---

## 2. Основний блок — відповіді на запитання

⏱️ 45–50 хв

Нагадайте студентам заздалегідь фіксувати питання, які виникають під час
навчання. Студенти можуть запитувати про поточну тему, матеріали, домашнє
завдання або проєкт.

### Рекомендації під час відповідей

- Рухайтеся за таблицею та позначайте розглянуті питання.
- Для подій уточнюйте, де розміщений слухач і який елемент є цільовим.
- Для деструктуризації спочатку визначайте структуру початкових даних.
- Дайте пряму відповідь, поясніть причину та покажіть короткий приклад.
- Для помилки попросіть студента пояснити код і очікуваний результат.
- Залучайте групу та перевіряйте розуміння схожим прикладом.
- Тривалі питання залишайте для повернення після основної черги.

Пріоритет — відповісти на всі запитання. За великої кількості питань практику
скоротіть або пропустіть.

## 3. Додатковий блок — практична робота

⏱️ 20–30 хв за наявності часу

### Матеріали

- **Стартові файли:** [додати посилання](STARTER_FILES_URL_PLACEHOLDER)
- **Рішення для менторів:** [додати посилання](SOLUTION_FILES_URL_PLACEHOLDER)

Набір містить 5 послідовних задач. Перші чотири можна обирати окремо за
питаннями групи. П'ята задача комплексна: залиште на неї 15–20 хвилин і
виконуйте після повторення делегування та деструктуризації.

### 🟢 Задача 1. Цільова кнопка

Визначити кнопку, на якій виник клік усередині контейнера.

**Що тренуємо:** спливання, `event.target`, `event.currentTarget`.

### 🟢 Задача 2. Дані користувача

Дістати ім'я та пошту з об'єкта за допомогою деструктуризації.

**Що тренуємо:** деструктуризацію об'єкта, перейменування, значення за
замовчуванням.

### 🟡 Задача 3. Меню з делегуванням

Одним обробником керувати активним пунктом меню.

**Що тренуємо:** делегування подій, `closest()`, `classList`.

### 🟡 Задача 4. Клік по картці та кнопці

Додати обробники картці товару та вкладеній кнопці так, щоб клік по кнопці не
запускав обробник картки.

**Що тренуємо:** спливання подій, `stopPropagation()`, порядок виклику
обробників.

### 🔴 Задача 5. Інтерактивний графік продажів із Chart.js

Підключити Chart.js через CDN, підготувати дані продажів, створити стовпчикову
діаграму та перемикати її між тижнем і місяцем через делегований обробник.

**Що тренуємо:** підключення бібліотеки через CDN, читання API Chart.js,
`new Chart()`, деструктуризацію в колбеках, `map()`, делегування, `dataset`,
оновлення даних бібліотеки та `chart.update()`.

---

## 4. Завершення зустрічі

⏱️ 5 хв

- Уточніть, чи залишилися запитання в учасників або в чаті.
- Перевірте таблицю, щоб жодне питання не залишилося без відповіді.
- Підсумуйте висновки й назвіть матеріали для повторення.
- Подякуйте за активність і нагадайте фіксувати нові питання.
