# Q&A-сесія: делегування, бібліотеки та деструктуризація

### 🟢 Задача 1. Цільова кнопка

Визначити кнопку, на якій виник клік усередині контейнера.

**Що тренуємо:** спливання, `event.target`, `event.currentTarget`.

### 🟢 Задача 2. Дані користувача

Дістати ім'я та пошту з об'єкта за допомогою деструктуризації.

**Що тренуємо:** деструктуризацію об'єкта, перейменування, значення за
замовчуванням.

### 🟡 Задача 3. Меню з делегуванням

Одним обробником керувати активним пунктом меню.

**Що тренуємо:** делегування подій, `closest()`, `classList`.

### 🟡 Задача 4. Клік по картці та кнопці

Додати обробники картці товару та вкладеній кнопці так, щоб клік по кнопці не
запускав обробник картки.

**Що тренуємо:** спливання подій, `stopPropagation()`, порядок виклику
обробників.

### 🔴 Задача 5. Інтерактивний графік продажів із Chart.js

Підключити Chart.js через CDN, підготувати дані продажів, створити стовпчикову
діаграму та перемикати її між тижнем і місяцем через делегований обробник.

**Що тренуємо:** підключення бібліотеки через CDN, читання API Chart.js,
`new Chart()`, деструктуризацію в колбеках, `map()`, делегування, `dataset`,
оновлення даних бібліотеки та `chart.update()`.
