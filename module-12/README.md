# Практика: async/await і пагінація товарів

Використай готовий застосунок пошуку товарів із попереднього модуля. Виконай
рефакторинг HTTP-запиту з ланцюжка промісів на `async/await` і додай
пагінацію через кнопку «Завантажити ще».

Стартовий шаблон уже містить:

- готову розмітку та стилі;
- встановлений Axios;
- пошук товарів через DummyJSON API;
- обробку запиту через `then()`, `catch()` і `finally()`;
- приховану кнопку `.load-more`;
- loader під кнопкою.

## Підготовка проєкту

Відкрий термінал у корені шаблону та встанови залежності:

```bash
npm install
```

Запусти локальний сервер:

```bash
npm run dev
```

Переконайся, що початковий пошук працює до початку рефакторингу.

## Частина 1. Рефакторинг HTTP-запиту

У файлі `products-api.js` зміни функцію `getProductsByQuery`.

Функція повинна:

1. бути асинхронною;
2. приймати два параметри — `query` і `page`;
3. виконувати запит через `await axios.get()`;
4. повертати `response.data` без використання `then()`.

Сигнатура функції:

```js
export async function getProductsByQuery(query, page) {
  // HTTP-запит
}
```

## Частина 2. Параметри пагінації

DummyJSON використовує параметри `limit` і `skip`:

- `limit` визначає кількість товарів в одній відповіді;
- `skip` визначає, скільки товарів потрібно пропустити.

Використовуй по 4 товари на сторінку:

```js
const PRODUCTS_PER_PAGE = 4;
```

Обчислюй `skip` із номера сторінки:

```js
const skip = (page - 1) * PRODUCTS_PER_PAGE;
```

Передай у `params` такі значення:

- `q: query`;
- `limit: PRODUCTS_PER_PAGE`;
- `skip`;
- `delay: 1000`.

## Частина 3. Стан пошуку

У `main.js` створи три змінні:

```js
let currentQuery = '';
let currentPage = 1;
let loadedProducts = 0;
```

- `currentQuery` зберігає останнє пошукове слово;
- `currentPage` зберігає номер наступної сторінки;
- `loadedProducts` зберігає кількість уже доданих товарів.

Під час нового пошуку:

1. збережи новий пошуковий рядок у `currentQuery`;
2. поверни `currentPage` до `1`;
3. поверни `loadedProducts` до `0`;
4. очисти попередні картки та повідомлення;
5. сховай кнопку «Завантажити ще»;
6. завантаж першу сторінку.

## Частина 4. Асинхронне завантаження

Створи асинхронну функцію `loadProducts()`.

На початку функції:

- покажи loader;
- сховай кнопку «Завантажити ще»;
- очисти попереднє повідомлення.

У блоці `try`:

1. дочекайся `getProductsByQuery(currentQuery, currentPage)` через `await`;
2. перевір масив `data.products`;
3. якщо перша сторінка порожня, покажи повідомлення про відсутність товарів;
4. додай нові картки до наявних через `insertAdjacentHTML('beforeend', ...)`;
5. збільш `loadedProducts` на кількість отриманих товарів;
6. збільш `currentPage` на `1` лише після успішного запиту.

У блоці `catch` покажи повідомлення:

```text
Не вдалося завантажити товари. Спробуйте ще раз
```

У блоці `finally` завжди приховуй loader.

## Частина 5. Кнопка «Завантажити ще»

Знайди кнопку `.load-more` і додай до неї обробник `click`.

Після натискання:

1. завантаж наступну сторінку через `await loadProducts()`;
2. не очищай попередні картки;
3. додай нові картки в кінець списку.

Створи функції:

- `showLoadMoreButton()` прибирає клас `is-hidden`;
- `hideLoadMoreButton()` додає клас `is-hidden`.

Поки виконується запит, кнопка має бути прихованою.

## Частина 6. Кінець колекції

DummyJSON повертає властивість `total` — загальну кількість товарів за
пошуковим запитом.

Після кожної успішної відповіді порівняй `loadedProducts` і `data.total`:

- якщо завантажено не всі товари, покажи кнопку;
- якщо завантажено всі товари, залиш кнопку прихованою та покажи повідомлення
  «Ви переглянули всі результати пошуку».

Кінець колекції може настати вже після першого запиту.

## Частина 7. Плавне прокручування

Після успішного завантаження наступної сторінки:

1. знайди першу картку `.product-card`;
2. отримай її висоту через `getBoundingClientRect().height`;
3. прокрути сторінку на дві висоти картки:

```js
window.scrollBy({
  top: cardHeight * 2,
  behavior: 'smooth',
});
```

Після першого пошуку прокручування виконувати не потрібно.

## Перевірка роботи

- Початковий запит виконується через `async/await`.
- У коді запиту немає ланцюжка `then()`.
- Новий пошук починається зі сторінки `1`.
- За один запит завантажується не більше чотирьох товарів.
- Кнопка прихована до появи результатів.
- Нові товари додаються до вже наявних.
- Під час запиту відображається loader.
- Після останньої сторінки кнопка зникає.
- Після додаткового завантаження сторінка плавно прокручується.
- Помилка не зупиняє роботу застосунку.
