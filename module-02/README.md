# Q&A-сесія: розгалуження, методи рядків і цикли

### 🟢 Задача 1. Бонус за замовлення

Змінити базове повідомлення лише за виконання однієї умови.

**Що тренуємо:** інструкцію `if`, блокову область видимості, змінну результату.

### 🟢 Задача 2. Стан рахунку

Обрати одне з двох повідомлень залежно від достатності коштів.

**Що тренуємо:** конструкцію `if...else`, порівняння чисел.

### 🟡 Задача 3. Рівень температури

Повернути одну з чотирьох категорій для різних числових діапазонів.

**Що тренуємо:** `if`, `else if`, `else`, розгалуження у функції та `return`.

### 🟢 Задача 4. Підпис теми

Створити один із двох рядків коротким умовним виразом.

**Що тренуємо:** тернарний оператор і логічне значення.

### 🟡 Задача 5. Спосіб доставки

Повернути повідомлення для текстової опції та передбачити невідоме значення.

**Що тренуємо:** `switch`, `case`, `default`, `return`.

### 🟡 Задача 6. Доступ до чату

Об'єднати кілька станів користувача у два логічні результати.

**Що тренуємо:** оператори `&&`, `||`, `!` і логічні значення.

### 🟡 Задача 7. Форматування посилання

Очистити й нормалізувати посилання, замінити протокол і додати завершальний
символ за потреби.

**Що тренуємо:** `trim()`, `toLowerCase()`, `startsWith()`, `endsWith()`,
`slice()` і розгалуження.

### 🟢 Задача 8. Зворотний відлік

Вивести послідовність чисел зі зменшенням лічильника до завершення умови.

**Що тренуємо:** цикл `while`, лічильник і декремент.

### 🟡 Задача 9. Сума чисел, кратних трьом

Перебрати числовий діапазон і накопичити суму лише потрібних значень.

**Що тренуємо:** цикл `for`, `%`, умову всередині циклу, накопичувач.

### 🔴 Задача 10. Перший дільник

Знайти перший дільник числа й припинити перебір одразу після знаходження.

**Що тренуємо:** цикл `for`, оператор `break`, функцію, `null` і `return`.
