# Q&A-сесія: об’єкти

### 🟢 Задача 1. Картка товару

Прочитати, змінити й додати властивості об’єкта, включно з вкладеною
властивістю.

**Що тренуємо:** створення об’єкта, крапкову нотацію, квадратні дужки, вкладені
властивості.

### 🟢 Задача 2. Статистика профілю

Порахувати кількість властивостей і сформувати рядки з ключами та значеннями.

**Що тренуємо:** `Object.keys()`, `Object.values()`, `length`, `join()`.

### 🟡 Задача 3. Пошук товару

Знайти товар за назвою в масиві об’єктів без урахування регістру.

**Що тренуємо:** масив об’єктів, `for...of`, доступ до властивостей,
`toLowerCase()`.

### 🟡 Задача 4. Банківський рахунок

Реалізувати методи об’єкта для поповнення, списання та отримання балансу.

**Що тренуємо:** методи об’єкта, `this`, зміну властивостей і розгалуження.

### 🔴 Задача 5. Оновлення налаштувань

Створити новий об’єкт налаштувань, об’єднавши стандартні та користувацькі
значення без мутації джерел.

**Що тренуємо:** `spread`, порядок властивостей, параметр `rest`.

### 🟢 Задача 6. Фонд зарплати

Підсумувати значення об'єкта. **Що тренуємо:** `Object.values()`, цикл.

### 🟢 Задача 7. Назви товарів

Зібрати властивості об'єктів. **Що тренуємо:** масив об'єктів, `for...of`.

### 🟡 Задача 8. Список справ

Додати методи керування справами. **Що тренуємо:** методи, `this`, масив у
властивості.

### 🟡 Задача 9. Поповнення складу

Знайти й оновити товар. **Що тренуємо:** пошук і зміну властивості.

### 🟡 Задача 10. Підсумок замовлення

Зібрати товари rest-параметром. **Що тренуємо:** rest, об'єкти, обчислення.
