# Q&A-сесія: контекст, прототипи та класи

### 🟢 Задача 1. Глобальний контекст

Переглянути значення `this` у модульному коді та під час звичайного виклику
функції.

**Що тренуємо:** глобальний контекст, звичайний виклик функції, `this`.

### 🟢 Задача 2. Метод кошика

Обчислити загальну вартість товарів у методі об’єкта.

**Що тренуємо:** контекст методу об’єкта, `this`, перебір масиву.

### 🟡 Задача 3. Привітання зі стрілковою функцією

Повернути стрілкову функцію з методу об’єкта та використати збережений контекст.

**Що тренуємо:** стрілкові функції, лексичний `this`, замикання.

### 🟢 Задача 4. Власні властивості

Отримати назви лише власних властивостей об’єкта.

**Що тренуємо:** власні та успадковані властивості, `Object.keys()`.

### 🟡 Задача 5. Ланцюжок прототипів

Створити об’єкт на основі готового прототипу та використати успадкований метод.

**Що тренуємо:** `Object.create()`, прототип, пошук властивостей.

### 🟢 Задача 6. Клас книги

Створити екземпляр класу з даними книги.

**Що тренуємо:** клас, конструктор, властивості екземпляра, `new`.

### 🟡 Задача 7. Лічильник

Керувати станом екземпляра через методи класу.

**Що тренуємо:** методи класу, `this`, зміна властивостей екземпляра.

### 🟡 Задача 8. Приватний код

Зберегти код у приватній властивості класу та перевіряти його через публічні
методи.

**Що тренуємо:** приватні поля й методи, інкапсуляція, перевірка умов.

### 🟡 Задача 9. Преміум-користувач

Створити дочірній клас, передати дані батьківському конструктору та
перевизначити метод.

**Що тренуємо:** `extends`, `super`, наслідування, перевизначення методів.

### 🔴 Задача 10. Онлайн-курс

Створити спеціалізований клас курсу з власною властивістю та методами.

**Що тренуємо:** класи, конструктори, методи, `extends`, `super`, наслідування.
