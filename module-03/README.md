# Q&A-сесія: масиви та функції

### 🟢 Задача 1. Останній учасник

Отримати перший і останній елементи списку, замінити одного учасника та вивести
довжину масиву.

**Що тренуємо:** індекси, `length`, читання та зміна елементів масиву.

### 🟢 Задача 2. Список тегів

Перетворити рядок тегів на масив, додати новий тег і сформувати оновлений рядок.

**Що тренуємо:** `split()`, `push()`, `join()`.

### 🟡 Задача 3. Спільні навички

Знайти спільні значення у двох масивах без дублювання результату.

**Що тренуємо:** `for...of`, `includes()`, `push()`, вкладене мислення про
колекції.

### 🟡 Задача 4. Найвища ставка

Створити функцію з довільною кількістю аргументів, яка повертає найбільше число.

**Що тренуємо:** `arguments`, цикл, локальну область видимості, `return`.

### 🔴 Задача 5. Унікальні замовлення

Об’єднати два масиви і повернути новий масив без повторів, не змінюючи початкові
дані.

**Що тренуємо:** `concat()`, перебір масиву, `includes()`, роботу з посилальними
типами.

### 🟢 Задача 6. Сума кошика

Підсумувати масив цін. **Що тренуємо:** `for...of`, накопичувач.

### 🟢 Задача 7. Зворотна черга

Створити перевернуту копію. **Що тренуємо:** індекси, цикл, `push()`.

### 🟢 Задача 8. Середня оцінка

Знайти середнє аргументів. **Що тренуємо:** `arguments`, цикл.

### 🟡 Задача 9. Адреса статті

Перетворити заголовок на slug. **Що тренуємо:** `split()`, `join()`, регістр.

### 🟡 Задача 10. Найдовше ім'я

Знайти найдовший рядок. **Що тренуємо:** перебір і порівняння.
